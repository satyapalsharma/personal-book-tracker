# Profilr - GitHub Profile README Generator

A visual tool to build a stunning GitHub profile README without writing markdown. Drag and drop sections like stats, skills, and social links, then export the generated markdown.

## Tech Stack

- React
- TypeScript
- Tailwind CSS
- Vite

## Setup

1. Clone the repository.
2. Run `npm install`.
3. Run `npm run dev` to start the development server.
4. Open http://localhost:5173 in your browser.
