# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-01-01

### Added

- **Visual profile builder** — Drag-and-drop interface for constructing a GitHub profile README.
- **Section management** — Add, reorder, and remove profile sections (About, Skills, Stats, Social Links, etc.).
- **Markdown preview** — Live preview of the generated profile markdown.
- **Export functionality** — Export the final profile README as a markdown file.
- **Theme toggle** — Switch between light and dark modes.
- **Undo/Redo** — Full undo/redo support for all editing actions.
- **Skills section** — Add and organize skills with icons.
- **Stats card** — Include GitHub stats cards in the profile.
- **Social links** — Add social media links to the profile.
- **Error boundary** — Graceful error handling at the component level.
- **Responsive layout** — Works on desktop and mobile viewports.
- **TypeScript** — Full type safety with strict mode.
- **Tailwind CSS** — Utility-first styling for rapid development.
